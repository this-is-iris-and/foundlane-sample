# Foundlane: sample website

A sample home page for **Foundlane**, a planned digital-services company that helps businesses in Zimbabwe get found online (websites, Google Maps, WhatsApp Business).

> **Built with AI:** this sample was designed and coded by Claude (Anthropic's AI) for Paule-Iris Djeni. It is a demo, not a client site. Prices, phone number and email are placeholders.

## Features
- Plain HTML, CSS and a tiny JavaScript file: no frameworks, fast on mobile data
- Mobile-first, responsive layout (phone, tablet, laptop)
- Light and dark mode: follows the device setting automatically, with a manual toggle that is remembered
- Accessible: real buttons and links, visible focus, keyboard-friendly FAQ
- Security basics: Content Security Policy, no third-party scripts, no forms or customer data

## Run locally
Open `index.html` in a browser.
